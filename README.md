# 🎵 Spotify Clone  

A responsive **Spotify Clone website** built using **HTML, CSS, and JavaScript**.  
It replicates the Spotify UI with smooth animations, responsive layout, and theme toggle.  

---

## ✨ Features  
-  Sidebar navigation with playlists & library  
-  Dark/Light theme toggle  
-  Fully responsive for mobile, tablet & desktop  
-  Smooth transitions & scroll animations  
-  Play/Pause controls with progress bar (UI simulation)  
-  Search bar (UI only / functional if connected with API)  

---

## Tech Stack  
- **HTML**  
- **CSS**  
- **JavaScript **
